Asset

app_icon_monochrome.svg

Drop this into res/drawable/ic_launcher_monochrome.xml (convert via Android Studio's "Asset Studio → Vector Asset") and reference it from your adaptive-icon XML: <monochrome android:drawable="@drawable/ic_launcher_monochrome"/>. Solid white only — Android will handle the tint.

Format: SVG (vector) Canvas: 512×512 Safe zone: centered, ~70% Color: #FFFFFF only
